# Ketong Ding — Personal Website

A lightweight, single-page academic portfolio hosted with GitHub Pages. It uses
plain HTML and CSS, so no package installation or build step is required.

## Updating the site

- Edit profile text, links, experience, and project descriptions in `index.html`.
- Replace `assets/profile-placeholder.svg` with a portrait and update the image
  path in `index.html` to `assets/profile.jpg`.
- Replace the project illustration with a real result figure when available.
- Adjust colours and responsive layout in `styles.css`.

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then select
`main` and `/ (root)`.

The website will appear at <https://zhaojingoo.github.io/>.
